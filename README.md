# AthenaDraw releases

Compiled builds of **AthenaDraw** (counterweight rigging submittal drawing generator) for Athena Theatrical.
This repo holds release binaries only; source is private. Builds are published automatically by CI
and picked up by the app's built-in updater.

Download the latest `AthenaDraw.exe` from **Releases**. Windows SmartScreen may warn on first run
(unsigned build): More info → Run anyway.
